Разработал сервис отслеживания посылок на языке Go (Golang) в рамках учебного практикума, реализующий функционал управления данными о посылках в базе данных SQLite. Проект относится к сфере логистики и веб-разработки, с целью обеспечения регистрации, отслеживания и управления статусами посылок для клиентов (например, службы доставки или пользователи). Использовались технологии: Go, SQLite, пакет database/sql, фреймворк тестирования testify (assert, require). Пользователи — службы доставки или клиенты, управляющие посылками через API.
